What the validator checks

Nine checks run on every handoff, and all of them run every time: the file's hash, the column set, each column's type, the allowed values, the numeric range, the null counts, the row count, the primary key and target, and the features the modelling crew asked for. Every failure is reported at once, because a partial answer sends someone back for a second round.
