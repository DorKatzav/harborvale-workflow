התחנה הראשונה לא בונה שום דבר מהפרויקט עצמו. היא מוודאת שהצנרת עובדת: ריפו, סביבה, בדיקות, CI, ואפליקציה קטנה שעולה ב-Railway ומדווחת איזה commit היא מריצה. כשזה עובד, כל תחנה הבאה היא "עוד קוד באותה צנרת".

01מה נבנה

  • ריפו עצמאי + GitHub ציבורי: DorKatzav/harborvale-workflow. תיקיית הקורס מתעלמת ממנו ב-.gitignore (כמו FunnelIQ). קומיט ראשון: מסמכי התכנון. PR ראשון: #1.
  • סביבת conda harborvale (Python 3.11.16). CrewAI הותקן בגרסה 1.15.20 (חדשה יותר מ-1.15.16 שיש ב-base). כל הגרסאות מוצמדות ב-requirements.txt: pandas 3.0.5, scikit-learn 1.9.0, Flask 3.1.3, pydantic 2.12.5, openai 2.54.0, gunicorn, pytest 9.1.1, ruff 0.16.6.
  • חבילת hv/ עם config.py: נתיבים, seed 42, תפקידי עמודות (מזהה, מטרה, מוגנות), מפת הישויות, היחידות, ומפעל ה-LLM (gpt-5-mini, בלי temperature).
  • Flask app/main.py עם /health שמחזיר גרסה, commit (מ-Railway או מ-git), האם יש מודל טעון, וזמן ריצה. דף בית זמני.
  • 8 בדיקות (health, config), ruff, GitHub Actions (ruff + pytest על כל push ו-PR; המפתח של OpenAI ריק ב-CI בכוונה).
  • Railway: railway.json + railpack.json + Procfile עם start command מפורש (הלקח מ-FunnelIQ), healthcheck על /health, libgomp1 ל-scikit-learn.
  • שער M0: scripts/gate.py --m 0, כולל סריקת סודות (מפתחות OpenAI ו-JWT) ובדיקה חיה מול LIVE_URL.

03מה למדנו

  • pip בסביבה החדשה הביא CrewAI 1.15.20 עם pandas 3.0.5. הכל מוצמד, אז Railway יתקין בדיוק את אותן גרסאות.
  • ruff format מנסה לפרמט גם קוד בתוך קבצי Markdown (הוא סימן את הדוגמאות ב-PLAN.md). ב-CI רץ רק ruff check, וזה בכוונה.
  • ה-CI הראשון נכשל: ב-GitHub Actions pytest רץ בלי שורש הריפו ב-sys.path, ומקומית python -m pytest מוסיף אותו. תוקן עם pyproject.toml (pythonpath = ["."]). לקח: לבדוק גם עם pytest ישירות, לא רק דרך python -m.

04תקרית קטנה שהשער תפס

המפתח נכתב לקובץ הלא נכון

מפתח ה-OpenAI ו-LIVE_URL הודבקו ב-.env.example (קובץ שנמצא ב-git) במקום ב-.env (שלא נמצא). סריקת הסודות של השער נכשלה מיד, לפני כל קומיט או push: המפתח לא הגיע לריפו. התיקון: התוכן הועבר ל-.env (מתעלמים ממנו ב-git, אומת), ו-.env.example שוחזר לגרסה הנקייה.

שתי הערות: (1) ה-URL הודבק בלי https://; השער מוסיף אותו עכשיו לבד, כי כך Railway מציג את הדומיין. (2) המפתח הופיע בפלט של השער במסך שלי. הוא לא נשמר בשום קובץ מלבד .env, אבל אם אתה רוצה להיות בטוח לגמרי, אפשר לסובב אותו ב-OpenAI (מוחקים ויוצרים חדש, עלות: דקה). זו החלטה שלך.
